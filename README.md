# Islamic Learning for Beginners

A simple, beautiful, and comprehensive website designed to introduce the fundamentals of Islam to beginners in a straightforward and accessible way.

## 🌐 Live Demo

View the website: [Islamic Learning for Beginners](https://rabdul-rafay123.github.io/Islamic-Learning/)

## 📚 Features

- **Clear Navigation** - Easy-to-use menu for quick access to different sections
- **Beautiful Design** - Modern gradient styling with smooth transitions
- **Responsive Layout** - Works on desktop, tablet, and mobile devices
- **Comprehensive Content** - Covers key Islamic concepts including:
  - What is Islam?
  - The Five Pillars
  - Short Lessons on Islam
  - Keeping Iman Strong
  - Farz and Obligations
  - Other Basics

## 📋 Sections Included

1. **About This Website** - Introduction and overview
2. **What is Islam?** - Understanding Islam and Key Beliefs
3. **Five Pillars of Islam** - The fundamental practices of Islam
4. **Short Lessons** - Educational lessons on various Islamic topics
5. **Keeping Iman Strong** - Ways to strengthen your faith
6. **Farz and Obligations** - Understanding religious duties
7. **Other Basics** - Additional fundamental concepts

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with gradients, animations, and backdrop filters
- **Responsive Design** - Mobile-first approach

## 🚀 How to Use

1. Clone this repository:
```bash
git clone https://github.com/rabdul-rafay123/Islamic-Learning.git
```

2. Navigate to the project directory:
```bash
cd Islamic-Learning
```

3. Open `index.html` in your web browser

## 💻 Running on GitHub Pages

This site is hosted on GitHub Pages. To enable GitHub Pages on your repository:

1. Go to your GitHub repository settings
2. Scroll to "GitHub Pages" section
3. Select `main` branch as the source
4. Your site will be available at `https://yourusername.github.io/repository-name/`
